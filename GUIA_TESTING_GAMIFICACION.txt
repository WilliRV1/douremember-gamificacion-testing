                        3. SETUP INICIAL
================================================================================

PASO 1: LIMPIAR NAVEGADOR (Si es primera vez)
--------------------------------------------
Si tienes sesiones anteriores, limpia localStorage:
1. Abre DevTools: F12
2. Application → LocalStorage
3. Busca entries de "auth", "userId", "userName", "userRole"
4. Elimina todas

PASO 2: VERIFICAR CONEXIÓN A SUPABASE
-------------------------------------
Las imágenes de familiares se cargan desde:
- randomuser.me (fotos públicas de ejemplo)
- Supabase Storage (audios y fotos de pacientes reales)

Si ves errores de CORS, revisa que en next.config.ts esté configurado:
```
remotePatterns: [
  { protocol: 'https', hostname: 'randomuser.me' },
  { protocol: 'https', hostname: '*.supabase.co' }
]
```

PASO 3: VERIFICAR AMBIENTE
--------------------------
Abre DevTools → Console (F12)
Deberías ver logs como:
✓ "🔍 Inicializando datos y verificando sesión..."
✓ "✅ Usuario logueado como: [nombre]"

Si ves errores de auth, revisa que localStorage tenga estos keys:
- authToken
- userId
- userName
- userRole

================================================================================
                            7. TROUBLESHOOTING
================================================================================

PROBLEMA: "Error: No hay token o ID de usuario"
──────────────────────────────────────────────────
CAUSA: localStorage no tiene credenciales
SOLUCIÓN:
1. Abre DevTools (F12)
2. Application → LocalStorage → http://localhost:3000
3. Verifica que existan estos keys:
   - authToken
   - userId
   - userName
   - userRole
4. Si no existen, intenta login de nuevo
5. Si aún no funcionan, limpia localStorage completamente:
   localStorage.clear() en console
   Luego recarga la página y haz login

PROBLEMA: "Las imágenes de familiares no cargan"
────────────────────────────────────────────────
CAUSA: CORS o next.config.ts no configurado
SOLUCIÓN:
1. Verifica que next.config.ts tenga:
   ```
   remotePatterns: [
     { protocol: 'https', hostname: 'randomuser.me' },
     { protocol: 'https', hostname: '*.supabase.co' }
   ]
   ```
2. Reinicia el servidor: npm run dev
3. Limpia caché del navegador: Ctrl+Shift+Del
4. Recarga la página: Ctrl+R (hard refresh)

PROBLEMA: "Mini-juego no carga / Error en metricas"
────────────────────────────────────────────────────
CAUSA: Posible problema con conexión a Supabase
SOLUCIÓN:
1. Verifica en .env que NEXT_PUBLIC_API_URL esté correcto
2. Abre DevTools → Network tab
3. Busca llamadas a API que retornen error
4. Si ves "Row Level Security" error:
   → Tabla familiares/minijuego_sesiones/minijuego_rondas tiene RLS habilitado
   → Contacta al admin para deshabilitar RLS

PROBLEMA: "Sesión se cierra al cambiar de pestaña"
──────────────────────────────────────────────────
CAUSA: Se usaba sessionStorage (obsoleto)
SOLUCIÓN:
✓ Sistema ahora usa localStorage (persiste)
✓ Si aún ocurre, limpia sessionStorage:
  1. DevTools → Application → SessionStorage
  2. Elimina todos los items
  3. Recarga página

PROBLEMA: "¿Por qué los datos se cargan muy lento?"
───────────────────────────────────────────────────
CONTEXTO: Las imágenes vienen de randomuser.me (CDN público)
✓ Primera carga: Puede tardar 1-2 segundos
✓ Cargas posteriores: Caché del navegador (< 100ms)
✓ Si persiste: Revisa tu velocidad de internet
  Prueba en: https://fast.com/

PROBLEMA: "¿Puedo cambiar los datos de prueba?"
─────────────────────────────────────────────────
SÍ, puedes:
1. Para modificar familiares: /users/cuidador → Editar/Eliminar
2. Para agregar nuevos: /users/cuidador → "Agregar Familiar"
3. Los datos se guardan en Supabase (tabla: familiares)
4. Para resetear todo, ejecuta:
   scripts/seed-familiares.mjs

PROBLEMA: "¿Cómo recargo todos los datos de test?"
──────────────────────────────────────────────────
Ejecuta el script de seed:
1. Terminal: cd al proyecto
2. npm run seed
   (Esto carga 6 familiares nuevos a Supabase)
3. Recarga la página
